# H무디 내선번호 관리

GitHub Pages용 정적 웹사이트입니다.

## 주요 기능
- 내선번호 6000~6499 관리
- 층, 사용자, 부서, 상태 관리
- 사용중 / 미사용 처리
- 내선번호 검색 및 전화 연결
- Excel 일괄 업로드
- Firebase Firestore 실시간 동기화

## 배포
1. GitHub에서 새 저장소를 만듭니다.
2. 이 압축파일의 파일을 저장소 루트에 업로드합니다.
3. Settings > Pages로 이동합니다.
4. Source를 Deploy from a branch로 선택합니다.
5. Branch는 main, Folder는 /(root)로 지정하고 Save를 누릅니다.

GitHub Pages는 루트의 index.html을 시작 파일로 사용합니다.
